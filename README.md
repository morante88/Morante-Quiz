# Morante Quiz

Versión definitiva construida con:
- Archivo Morante histórico.
- MORANTE_MEJORES_FAENAS_4_FAENAS_ANADIDAS(1).docx.

Banco incluido dentro de `index.html`: 5,195 preguntas.
No carga ningún banco externo, así que no puede quedarse en "Cargando banco de preguntas".

## Publicarlo en GitHub Pages
1. Crea un repositorio público llamado `morante-quiz`.
2. Sube los cuatro archivos de esta carpeta a la raíz.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

La URL será:
https://morante88.github.io/morante-quiz/
